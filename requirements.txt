# Hard requirements for the LCC Parks register toolkits: the build chain cannot run without these.
# Versions are the ones the v5 build was produced and verified on (11-Sep-2026).
#
#   python-calamine  every workbook READ (rule 19.8: a second openpyxl open of the register costs
#                    about 52 seconds against about 4 for calamine)
#   openpyxl         every workbook WRITE (write-only mode; it writes no cached values, which is why
#                    an unrecalculated file cannot pass verify)
#   lxml             streams the v127 sheet XML to recover rule 17 formula text, which calamine
#                    cannot return because it reads values only
#   cffi             the container ships a Debian cryptography whose Rust binding needs _cffi_backend
#                    and ships without it; anything that imports cryptography (pdfplumber does) then
#                    aborts the interpreter with a pyo3 panic, which took the env check down with it
#                    on 11-Sep-2026. Hard, not optional, so the check can never die that way again.
python-calamine==0.8.2
openpyxl==3.1.5
lxml==6.1.3
cffi==2.1.1
